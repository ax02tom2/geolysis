geolysis 大地工程分析系統｜Web 版

本專案包含五個大地工程分析模組：
1. Hoek–Brown 岩體參數
2. USCS／AASHTO 土壤分類
3. SPT 全修正
4. 沉陷與容許壓力
5. Terzaghi／Meyerhof／Hansen／Vesic 極限承載力

模組一的 RQD 僅保留人工輸入，供 FHWA GSI 定量計算使用；不提供岩心柱狀圖 PDF／DOCX 上傳、岩心影像辨識、採取率或 RQD 自動初估、斷裂候選標示及人工影像覆核。

已驗證環境：Python 3.11

啟動：
1. 建立並啟用 Python 虛擬環境。
2. python -m pip install -r requirements.txt
3. streamlit run app.py

Streamlit Cloud 部署時，選擇專案根目錄的 app.py。
