geolysis 大地工程分析系統｜Web 版

本專案包含五個大地工程分析模組：
1. Hoek–Brown 岩體參數
2. USCS／AASHTO 土壤分類
3. SPT 全修正
4. 沉陷與容許壓力
5. Terzaghi／Meyerhof／Hansen／Vesic 極限承載力

本 Web 專案包含整孔 DOCX／PDF 岩心柱狀圖解析、每列採取率與 RQD 影像初估、疑似斷裂候選標示，以及自動／手動托盤四角透視校正。影像初估仍須由工程人員逐列覆核，不取代現場編錄與實驗室試驗。

已驗證環境：Python 3.11

啟動：
1. 建立並啟用 Python 虛擬環境。
2. python -m pip install -r requirements.txt
3. streamlit run app.py

Streamlit Cloud 部署時，選擇專案根目錄的 app.py。
