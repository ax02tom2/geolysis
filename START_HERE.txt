geolysis 大地工程分析系統｜Web 版

本專案包含五個大地工程分析模組：
1. Hoek–Brown 岩體參數
2. USCS／AASHTO 土壤分類
3. SPT 全修正
4. 沉陷與容許壓力
5. Terzaghi／Meyerhof／Hansen／Vesic 極限承載力

岩心照片、AI 判釋、採取率影像初估及 RQD 影像估算不在本 Web 專案內，請使用獨立 Windows 單機工具。

已驗證環境：Python 3.11

啟動：
1. 建立並啟用 Python 虛擬環境。
2. python -m pip install -r requirements.txt
3. streamlit run app.py
