# 整孔岩心柱狀圖與 RQD 影像初估操作說明

版本日期：2026-11-12

## 1. 輸入檔案

- 支援整孔 DOCX 或 PDF，不必先把每列照片拆成獨立檔案。
- 目前採用的岩心箱規格為每箱 4 m、每列 1 m；系統固定以每列 1,000 mm 建立名義量測長度。
- PDF 會優先擷取內嵌岩心照片，並保留頁面影像供原頁疊圖檢視；DOCX 會擷取內嵌岩心照片並逐列顯示。
- PDF 頁首若有可讀取的深度範圍，系統會結合第一列列號推定深度起點。若頁首是掃描影像或無法讀取，使用者只需輸入一次第一列起始深度；不要求逐列輸入結束深度。
- 若檔案的列號缺失或不連續，系統會提出警告，深度索引須人工核對。

## 2. 原始影像與校正

- PDF 原始頁面會直接疊加逐列初估結果；原始上傳檔案不會被修改。
- 每列可選擇 180° 旋轉，以維持水平 1 m 量測軸。
- 可選擇裁除托盤邊框；短邊小於 80 px 的列會停用裁切，以避免低解析度影像失真。
- 可選擇自動偵測藍色托盤四角。系統先顯示四角候選，必須由使用者確認四角位於同一托盤外框後，才會套用透視校正。
- 可按列校正實際 1 m 量測起訖範圍。若沒有手動校正，系統以擷取列影像的原始寬度作為名義 1 m 比例尺；透視校正後則以校正影像寬度重新換算。
- 校正影像只供分析，不會覆寫原始 PDF／DOCX 或原始頁面。

## 3. 採取率與 RQD 初估

每列先由影像演算法估計：

- 岩心本體候選區間。
- 空隙候選區間。
- 不確定區間。
- 疑似天然節理、機械破損及其他斷裂候選位置。

採取率依影像辨識的岩心本體區間總長度除以 1,000 mm 初估。即使斷裂候選尚未覆核，採取率仍可先顯示；若候選未覆核，RQD 會維持待覆核。

RQD 覆核規則：

1. **天然節理**：切分岩心段；只有長度至少 100 mm 的段落計入 RQD。
2. **機械破損**：不作為天然節理切分，破損段可依原岩心段重新接合。
3. **非斷裂／誤判**：不切分岩心段。
4. **待確認**：不計算最終 RQD，直到候選全部覆核。
5. **沒有偵測到候選**：不會自動假定 RQD=100%；使用者必須檢視該列並明確確認沒有需要切分的天然節理，才會計算該列 RQD。

## 4. 重要限制

- 這是影像初估，不是現場實測編錄；遮擋、岩心旋轉、泥水、反光、托盤顏色、鏡頭畸變及影像比例尺都會影響辨識。
- 藍色托盤辨識以目前 HSV 色彩範圍為基礎；非藍色托盤或藍灰色岩心可能降低辨識率。若未通過影像品質檢核，不應把空白結果解讀為沒有岩心或沒有斷裂。
- 透視校正只改善影像幾何形狀；真實比例仍須依每列實際 1 m 長度或人工量測校正確認。
- 若 PDF 是整頁掃描圖、沒有可擷取的內嵌照片或列號文字，現行解析器不會自動 OCR 整頁；需使用可擷取照片的 DOCX／PDF，或人工確認深度。
- 照片不能直接提供完整岩石單軸抗壓強度 UCS；UCS 應以實驗室試驗或有明確依據的地質資料取得。
- 正式工程 RQD 應由岩心現場編錄與專業人員覆核，不可只憑影像初估值作為設計唯一依據。

## 5. 執行與測試

- 網頁版不呼叫付費 AI 服務；影像分析使用本機 OpenCV 演算法。
- 執行環境依 requirements.txt 安裝 OpenCV headless、PyMuPDF、python-docx 等必要套件。
- GitHub Actions 完整測試會自動探索 tests/ 目錄；目前 CI 也包含 PDF／DOCX 解析、影像分段、斷裂候選、快取指紋與 Streamlit AppTest。
