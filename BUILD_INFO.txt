Geolysis Core Analysis V3.1 - PDF parser and false-segmentation guard
Build time: 2026-11-04T15:17:13+08:00
Timezone: Asia/Taipei (UTC+08:00)

This build includes:
- PDF image placement threshold corrected so the first box on each page is retained.
- Partial final-box images are detected and are not cropped a second time.
- High blue-mask coverage guard prevents likely blue-grey core from being silently classified as tray background.
- Regression tests for row splitting and the supplied H25-1B 50 m PDF (fixture supplied through H25_CORE_PDF).

Known limitations:
- This is not a validated automatic natural-joint/mechanical-break classifier.
- The existing Hough detector found only two candidate rows in the supplied 50-row PDF; most rows still require visual review.
- Automatic core occupancy remains a heuristic. Eight rows were blocked by the new ambiguity guard; the other rows are not thereby certified as correct.
- Streamlit Cloud/browser deployment was not tested in this environment.
- This package does not include storage.py or Google Sheets engineering-cost storage.
