Module 5 seismic overturning moment/eccentricity — PR #73: the residual-pore-pressure bearing workflow accepts signed seismic base moment components M_B,E and M_L,E from structural analysis. Static eccentricities are converted to signed static moments V·e using independently selected B/L directions. For nonzero seismic moment inputs, both horizontal earthquake directions (H±khW) are combined with both vertical cases (V±kvW), giving four combinations. Each combination recalculates eB=|M_B|/V_eq, eL=|M_L|/V_eq, B′=B−2eB and L′=L−2eL before rebuilding the Meyerhof-based USACE resistance factors. If any combination loses positive compression-contact dimensions or the effective long/short axes swap, the function suppresses the governing numeric resistance and requires a separate contact/biaxial analysis. The UI warns when seismic moments are left at zero; the engine does not guess the seismic force height. This is still a single horizontal action-axis approximation and does not model arbitrary azimuth, torsion, simultaneous biaxial earthquake action, sloping base/ground, seismic qeq/FS, soil inertia or liquefaction-induced residual strength.
