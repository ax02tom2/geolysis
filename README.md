# 🧱 大地工程與岩石力學分析網頁系統 (Streamlit 實戰版)

這是一套專為大地工程師、工程地質師及邊坡穩定分析人員設計的專業網頁應用程式，採用 **Streamlit** 開發。系統將岩石力學（Hoek-Brown 2002 廣義準則）、土壤力學（USCS/AASHTO 分類）、SPT 標準貫入試驗全修正，以及淺基礎承載力四大理論完美整合在一個清爽、互動性極高的單一頁面中。

---

## 🛠️ 技術架構與依賴套件

* **Python 3.11+**
* **Streamlit** (網頁互動介面與狀態管理)
* **Pandas** (鑽孔數據表格互動編輯與資料處理)
* **Plotly** (地層剖面圖、Hoek-Brown 非線性破壞包絡線互動繪圖)
* **Geolysis** (大地工程輔助開源計算庫)

### `requirements.txt`
```text
streamlit
pandas

```

## 🔬 五大核心模組功能拆解

### 1. 模組一：Hoek-Brown (2002) 岩體強度與等效 $c', \phi'$ 推估
* **GSI 現場對照矩陣**：內建「岩體結構」與「節理面狀況」的交叉查表工具，自動判定地質強度指標 ($GSI$)。
* **常見岩性參數預設**：內建台灣常見岩石（砂岩、頁岩、泥岩、板岩、片岩、花崗岩等）的材料常數 $m_i$。
* **非線性破絡線與等效莫耳－庫倫**：依據邊坡高度或隧道深度對應的極限圍壓範圍 ($\sigma_{3\max}$)，自動擬合出等效凝聚力 $c'$ 與內摩擦角 $\phi'$，並計算岩體變形模數 ($E_m$) 與整體抗壓強度 ($\sigma_{cm}$)。
* **Plotly 視覺化**：繪製 Hoek-Brown 非線性曲線與等效莫耳－庫倫直線的主應力 ($\sigma_1$ vs. $\sigma_3$) 比較圖。

### 2. 模組二：土壤分類系統 (USCS & AASHTO)
* **阿太堡限度與粒徑分佈**：計算液性限度 ($LL$)、塑性限度 ($PL$)、塑性指數 ($PI$)、均勻係數 ($C_u$) 與曲率係數 ($C_c$)。
* **統一土壤分類法 (USCS)**：自動判定符號（如 `SC`, `CL`, `ML`, `CH`）及完整中文工程描述。
* **AASHTO 分類與群指數 ($GI$)**：評估路基材料優劣與群指數。

### 3. 模組三：SPT 標準貫入試驗全修正 (SPT Corrections)
* **能量與器材修正 ($N_{60}$)**：考量錘擊效率 ($E_m$)、鑽孔直徑 ($C_B$)、取樣器型式 ($C_S$) 與鑽桿長度 ($C_R$)。
* **覆土壓力修正 ($C_N$)**：內建 **7 大學者公式**（Liao & Whitman, Skempton, Peck, Seed, Kayen, Bazaraa）。
* **全鑽孔批次剖面**：透過 `st.data_editor` 進行多深度鑽孔數據編輯，並自動繪製深度 vs. $N_{60} / (N_1)_{60}$ 剖面折線圖。

### 4. 模組四：容許承載力與沉陷控制 (ABC)
* **經驗設計法**：基於 Bowles (1997) 與 Meyerhof (1956) 的經驗公式。
* **基礎型式**：支援獨立基礎、條形基礎、方形基礎與筏式基礎。
* **環境修正**：包含深度修正因數 ($f_d$) 與地下水位修正因數 ($C_W$)，對應使用者設定的容許沉陷量 ($S_e$)。

### 5. 模組五：極限承載力四大理論 (UBC)
* **四大經典理論**：Terzaghi (1943)、Meyerhof (1963)、Hansen (1970)、Vesic (1973)。
* **參數無縫連動**：支援手動輸入，或**一鍵直接帶入**模組一 (Hoek-Brown) 的等效 $c', \phi'$ 或模組三的 SPT 經驗推估值。
* **全套修正係數**：完整實作形狀係數 ($s$)、深度係數 ($d$)、載重傾斜係數 ($i$)、基底/地面傾斜係數 ($b, g$)、偏心有效面積 ($B', L'$) 以及三階段地下水位單位重折減。
* **明細分解表**：輸出各項承載力係數 ($N_c, N_q, N_\gamma$) 與百分比貢獻明細。

## 🤖 給 AI 協作者與維護者的開發指引

如果你是協助維護或擴充此程式碼庫的 AI 助手，請遵守以下原則：

1. **維持純 Python 與 Streamlit 規範**：除非有特殊需求，否則請保持單一檔案 (`app.py`) 的簡潔架構。所有 UI 元件與互動邏輯請善用 `st.expander` 與 `st.columns` 組織。
2. **嚴守大地工程專業邏輯**：當修改或新增力學公式（如承載力或岩石力學準則）時，必須嚴格遵循國際標準大地工程參考文獻（Bowles, Das, Hoek & Brown 2002）。
3. **介面語言與規範**：使用者介面標籤、數據圖表名稱與工程描述請統一使用**繁體中文**；數學與科學公式則請一律採用 LaTeX 格式（行內用 `$`，獨立行用 `$$`）。
